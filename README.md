# Vila Voz

Conversa por voz com os agentes da Vila Sete (Seven Films Brazil): fala, o agente responde em voz alta, mãos-livres ou segurando para falar.

- Página estática (GitHub Pages), salva na Tela de Início do iPhone.
- O processamento roda numa função no Supabase. Nenhuma chave fica neste repositório; o acesso é protegido por código.
